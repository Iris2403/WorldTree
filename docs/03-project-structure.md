Root-level `Assets/` stays clean. Third-party imports (if ever approved) go in `Assets/ThirdParty/<Vendor>/`, never mixed into `Assets/WorldTree/`.

## 2. Naming conventions

| Thing | Convention | Example |
|---|---|---|
| C# types and files | PascalCase, one public type per file, file name = type name | `BoardModel.cs` |
| Namespaces | `WorldTree.<Assembly>.<Feature>` | `WorldTree.Core.Generators` |
| Private fields | `_camelCase` | `_charges` |
| Stable data IDs | `lowercase.dotted`, never renamed after release | `item.nature.03`, `gen.seed_pouch`, `area.sunlit_glade` |
| Localization keys | `domain.context.name` | `item.nature.03.name`, `ui.energy.full` |
| ScriptableObject assets | `<Type>_<Name>` | `Chain_Nature.asset`, `Gen_SeedPouch.asset`, `Area_01_SunlitGlade.asset` |
| Sprites | `<chain>_<LL>_<name>` | `nature_03_sapling.png` |
| Prefabs | PascalCase | `ItemView.prefab` |
| Scenes | PascalCase | `Boot.unity` |

## 3. Asset specifications

| Asset | Spec |
|---|---|
| Item and generator icons | 256×256 PNG, transparent, centred, about 8% padding, top-left light, consistent outline. Imported as Sprite (Single), with mipmaps off |
| Atlases | One SpriteAtlas per domain (`Items_Nature`, `UI_Common`, and so on), max 2048×2048, ASTC 6×6 (iOS and Android) |
| UI art | 9-slice panels authored at 2× and imported with borders set |
| Character portraits | 1024×1024 PNG, expression variants as separate sprites |
| Environments | Layered: a **corrupted** layer and a **restored** layer per restoration step, so each completed task can cross-fade |
| Music | OGG Vorbis, streaming, −14 LUFS, seamless loops |
| SFX | WAV source, imported as compressed in memory (ADPCM), short |
| Fonts | TMP SDF assets, licensed for app embedding (OFL preferred). Licence stored in `Fonts/` |

## 4. Version control

- Commit `.meta` files with every asset, always. Unity generates them; never hand-write them.
- `.gitignore`: Unity standard (ignores `Library/`, `Temp/`, `Obj/`, `Build*/`, `Logs/`, `UserSettings/`, IDE files).
- **Git LFS (recommended before art arrives):** track `*.png *.psd *.wav *.ogg *.ttf *.fbx`. It needs `git lfs install` on each machine that commits art, so it will be set up together with the user when the first real art lands.
- Enable *Edit → Project Settings → Editor → Asset Serialization: Force Text* and *Version Control: Visible Meta Files* (the Unity 6 defaults; verify).
